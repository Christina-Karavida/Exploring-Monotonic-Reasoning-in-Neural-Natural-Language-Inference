## How to run the Code
All experiments for this thesis were run using Google Colab Pro and are organised in scripts Jupyter notebooks and Python scripts.
To use the code of this thesis:

1. Create a folder in Google Drive named `thesis_code`.
2. Clone this repository in this folder ( use: !git clone https://github.com/Christina-Karavida/Exploring-Monotonic-Reasoning-in-Neural-Natural-Language-Inference.git )
3. Keep the structure of the repository intact, and run the notebooks found in the `notebooks` folder.
